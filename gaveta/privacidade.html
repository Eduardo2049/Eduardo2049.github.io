Política de privacidade

Aplicativo "Gaveta de Fatos" · atualizada em 6 de novembro de 2026

O aplicativo "Gaveta de Fatos" é uma ferramenta pessoal que publica os vídeos do canal Gaveta de Fatos no YouTube. Ele é usado apenas pelo dono do canal, no próprio computador.

Quais dados o aplicativo acessa

Depois do login do Google feito pelo dono do canal, o aplicativo acessa, pela YouTube Data API e pela YouTube Analytics API, somente o canal autorizado:

  • a identificação do canal (id e nome), para conferir que os vídeos vão para o canal certo;
  • os vídeos do canal: envio, título, descrição, tags, capa, status de privacidade e data de publicação;
  • os comentários que o próprio canal publica nos seus vídeos;
  • as estatísticas dos vídeos do canal (visualizações, curtidas, comentários e tempo de exibição).

O aplicativo não coleta dados de espectadores nem de outras contas do Google, não usa cookies e não tem anúncios.

Como os dados são usados e guardados

  • Os dados são usados apenas para publicar e acompanhar os vídeos do próprio canal.
  • O token de acesso e as informações dos vídeos ficam guardados só no computador do dono do canal. Nada é enviado a servidores do aplicativo (ele não tem servidor).
  • Os dados não são vendidos, compartilhados nem transferidos a terceiros, e não são usados para publicidade nem para treinar modelos de inteligência artificial.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O aplicativo também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Para apagar os dados guardados, basta excluir o token e os arquivos do aplicativo no computador onde ele roda.
